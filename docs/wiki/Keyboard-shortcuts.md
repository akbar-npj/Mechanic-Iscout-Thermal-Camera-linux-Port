# Keyboard shortcuts

Every key below also has an on-screen control — an icon on the left rail, a row in
the right panel, or a setting in the [Settings](Settings.md) dialog. The keyboard
is a convenience, never the only way.

> **The letters are case-sensitive.** Where a capital letter is shown, hold
> **Shift**. This matters most for the four camera settings (`e` vs `A`/`R`/`D`)
> and for `S`/`L`/`M`, which are different from `s`/`l`/`m`.

## Measuring

| Key | Action |
|---|---|
| `p` | Point tool |
| `l` | Line tool |
| `b` | Box (rectangle) tool |
| `o` | Polygon tool |
| `n` | No tool — clear the measurement |
| `m` | Show / hide the hottest and coldest markers |
| `c` | Chart analysis — annotate the line's chart (puts the line tool up) |
| `a` | Arm / disarm the temperature alarm |
| `i` | Toggle the isotherm |

## Notes (Mark)

| Key | Action |
|---|---|
| `T` | Arm the Text tool (press again to put it away) |
| `w` | Arm the Arrow tool (press again to put it away) |
| `Ctrl+Z` | Undo the last note |
| `Ctrl+Y` (or `Ctrl+Shift+Z`) | Redo |
| `Ctrl+R` | Reset — remove all notes |

## The camera

| Key | Action |
|---|---|
| `e` | Arm emissivity (press again to walk the ladder) |
| `A` | Arm ambient |
| `R` | Arm reflected |
| `D` | Arm distance |
| `y` | Send the armed value |
| `n` or `Esc` | Cancel an armed value |
| `d` | Show / hide the device panel |
| `r` | Retry the camera connection now |
| `q` | Quit (never swallowed, even while a value is armed) |

## Saving

| Key | Action |
|---|---|
| `s` | Save a still (`.dyt.jpg` + `.png`) |
| `v` | Start / stop recording a clip |
| `g` | Show / hide the gallery |

## In the gallery

| Key | Action |
|---|---|
| `↑` or `k` | Move the highlight up |
| `↓` or `j` | Move the highlight down |
| `Return` or `o` | Open the highlighted item |
| `x` | Export the highlighted still as a PNG |
| `space` | Pause / resume a playing clip |
| `Esc` | Close the list, or stop a clip, and return to the live view |

## The picture

| Key | Action |
|---|---|
| `1`–`0` | Choose one of the first ten palettes |
| `.` / `,` | Next / previous palette |
| `u` | Cycle the temperature unit (C → F → K) |
| `t` | Toggle the range between automatic and fixed |
| `F` | Rapid Diagnostics — auto-fit the range |
| `S` `L` `M` | Circuit mode: short-circuit / large leak / small leak |
| `P` `C` | 3D height mode: morphological / colour changes |
| `h` `H` | Flip the picture horizontally / vertically |
| `+` `-` | Zoom in / out |
| `z` `Z` | Super-resolve the visible / thermal plane |
| `f` | Cycle the imaging (fusion) pattern |
| `[` `]` `;` `'` | Nudge the thermal/visible alignment |

## The window

| Key | Action |
|---|---|
| `F11` | Full screen on / off |
| `F1` or `?` | About box |
| `q` | Quit |

## The in-app guide

If you forget these, press **`F1`** for the About box, or click **Tutorials** on
the rail for the full scrollable guide — the same text the app itself shows.
